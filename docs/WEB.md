# Веб-панель KeenDesk

Панель показывает состояние `hbbs`/`hbbr`, счётчик падений, настройки ID/relay/Key, последние строки журналов и результаты `doctor`. Кнопки копирования помогают перенести параметры в обычный клиент RustDesk. Сервер API в клиенте по-прежнему оставляйте пустым: эта панель не является RustDesk Pro API.

Панель **только для чтения**. Обновление, остановка, настройка firewall и удаление доступны через SSH. Панель не меняет клиентов, не показывает приватный ключ и не использует внешние CDN, шрифты или аналитику.

## Включение через ZeroTier

В SSH Entware, заменив адрес и интерфейс своими:

```sh
rustdeskctl web --listen 10.147.17.1 --interface zt0
rustdeskctl web-token
```

Откройте `http://10.147.17.1:18082` с устройства, подключённого к этой VPN, и вставьте ключ из второй команды. Это отдельный случайный ключ панели, не публичный Key RustDesk и не SSH-пароль. Параметры сохраняются в `/opt/etc/rustdesk/web.json` с правами 600. Ключ не передаётся в URL, не записывается в access-log и хранится в браузере только в памяти страницы. После обновления страницы потребуется снова войти.

Допускается точный VPN-интерфейс `zt…`, `tun…`, `tap…` или `ppp…`, уже разрешённый для RustDesk. Адрес должен быть назначен этому интерфейсу и принадлежать диапазону 10/8, 172.16/12 или 192.168/16. Wildcard `0.0.0.0`, WAN и обычный LAN-интерфейс для панели не допускаются. Если VPN выдаёт другой диапазон, используйте localhost и SSH-туннель.

Панель использует HTTP внутри уже зашифрованного VPN. **Не публикуйте её через KeenDNS и не пробрасывайте порт в Интернет.** Собственная цепочка `RDW_INPUT` разрешает localhost и выбранный VPN-интерфейс с текущими ограничениями подсетей RustDesk; остальные входящие соединения на TCP 18082 блокируются, включая IPv6. Изменение списка интерфейсов RustDesk автоматически ограничивает и панель.

## Localhost и SSH-туннель

По умолчанию панель выключена. Команда без параметров при первом включении выбирает только localhost:

```sh
rustdeskctl web
rustdeskctl web-token
```

На своём компьютере откройте SSH-туннель, сохраняя номер локального порта:

```sh
ssh -p 222 -L 18082:127.0.0.1:18082 root@АДРЕС_РОУТЕРА
```

В браузере: `http://127.0.0.1:18082`. Туннель должен оставаться открытым. Заголовки Host и Origin проверяются; другие имена/порты в URL отклоняются.

## Обслуживание

```sh
rustdeskctl web          # показать адрес уже включённой панели
rustdeskctl web-token    # показать ключ входа только root
rustdeskctl web --disable
```

Панель запускается вместе с сервером, если включена. При недоступном VPN-адресе во время загрузки проверьте `web-startup.log`, дождитесь VPN и выполните `rustdeskctl restart`. Недоступность панели не означает отказ relay. Проверка `doctor` из панели кэшируется на 30 секунд, чтобы повторные клики не создавали лишнюю нагрузку.

Если браузер запрещает автоматическое копирование из HTTP-страницы, поле выделяется: нажмите Ctrl+C. Веб-панель не устанавливает расширения и не запрашивает доступ к клиенту RustDesk.
