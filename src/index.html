Ваш сервер RustDesk

Состояние служб, проверка соединения и настройки для клиентов — в одном месте.

Ключ выдаёт команда rustdeskctl web-token на роутере. Это отдельный ключ, не Key клиента RustDesk.

Состояние сервера

Подключение клиентов

Заполните на обоих устройствах RustDesk → Настройки → Сеть → ID/Ретранслятор.

Сервер API — пусто. WebSocket, «Отключить UDP» и небезопасный TLS — выключены. Оба клиента должны иметь маршрут до сервера.

Диагностика

Проверяет службы, базу, ключи, firewall, ID по TCP/UDP и передачу данных через relay.

Проверка локальная. Доступ через VPN и сеанс рабочего стола проверяются с клиентских устройств.

Журналы

Панель только для чтения. Она не меняет клиентские настройки и не публикует приватный ключ сервера.
